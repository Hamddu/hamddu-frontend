# 프론트 배포 전 보강 문서

앱 배포 전에 프론트에서 마무리하거나 확인하면 좋은 항목입니다. 우선순위는 실제 배포 리스크 기준입니다.

## 필수

### 1. FCM / 푸시 알림 완성
- iOS `GoogleService-Info.plist` 앱에 포함
- Android `google-services.json` 확보
- Firebase Console에 iOS APNs `.p8` 키 업로드
- 실기기에서 알림 권한 팝업 노출 확인
- 발급 토큰 `POST /api/notifications/device-tokens` 등록 성공 확인
- 백엔드 테스트 푸시 수신 확인

현재 프론트에는 로그인 후 기기 푸시 토큰을 등록하는 기본 배선이 들어가 있습니다. iOS는 Firebase 설정 파일/APNs 설정 전까지 완전한 FCM 검증이 어렵습니다.

### 2. 실기기 회귀 테스트
- SNS 로그인
- 설문/닉네임 등록
- 홈 기법 맵 스크롤/탭 전환
- 영상 이어보기 저장
- 30초 이상 시청 후 완료 처리
- 인증 게시글 제출
- 커뮤니티 게시글/댓글/신고
- 마이페이지 나의 인증 게시글
- 코카운터 저장/삭제

### 3. 배포용 앱 식별자 정리
- iOS/Android bundle id: `com.hamddu.app`
- Firebase 앱 등록 bundle id와 일치 확인
- Xcode Signing Team 확인
- 앱 이름/아이콘/스플래시 최종 확인

## 권장

### 1. 에러/빈 상태 UX 보강
- 네트워크 실패 시 재시도 버튼
- 게시글/인증글/댓글 빈 상태 문구
- 이미지 업로드 실패 시 안내
- 토큰 만료 후 재로그인 흐름 확인

### 2. 키보드/세이프에어리어 QA
- 게시글 작성 화면 키보드 노출
- 댓글 입력창 키보드 노출
- iPhone 작은 화면/노치 화면 확인
- 전체 화면 모달 safe area 확인

### 3. 영상 플레이어 QA
- 재생/일시정지
- 재생 속도 변경
- progress bar가 영상을 가리지 않는지
- 앱 종료 후 이어보기 복원
- 이미 인증한 영상에서 완료 버튼 미노출

## 나중

### 1. 푸시 설정 화면
- 사용자가 알림 수신 여부를 앱 안에서 확인
- 권한 거부 시 OS 설정으로 이동

### 2. 운영 편의
- API 실패 로그 수집
- 최소 크래시 리포팅 연동
- 배포 빌드 체크리스트 자동화

## 백엔드 확인 필요

- `POST /api/notifications/device-tokens` 최종 payload 확정
- iOS APNs 토큰 저장/발송 처리 가능 여부 확인
- FCM 테스트 발송용 어드민/스크립트 준비
- 토큰 갱신/중복 등록 처리 정책 확인
